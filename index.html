أساسيات الأمن السيبراني

Cybersecurity Fundamentals

يعني إيه أمن سيبراني؟

هو حماية الأجهزة والشبكات والتطبيقات والبيانات من الوصول غير المصرح به أو التعديل أو التعطيل.

ثالوث CIA

  • Confidentiality — السرية: البيانات يشوفها الأشخاص المصرح لهم فقط.
  • Integrity — سلامة البيانات: البيانات تفضل صحيحة وغير معدلة دون إذن.
  • Availability — التوافر: الأنظمة تكون متاحة وقت الحاجة.

خطوات الحماية

  • استخدم كلمة مرور قوية وفريدة.
  • فعّل المصادقة الثنائية.
  • حدّث البرامج ونظام التشغيل.
  • راجع الروابط والمرفقات قبل فتحها.
  • احتفظ بنسخة احتياطية من الملفات المهمة.

أمن الشبكات

Network Security

مفاهيم مهمة

  • IP: عنوان منطقي لجهاز على الشبكة.
  • MAC: عنوان واجهة الشبكة.
  • DNS: يحوّل أسماء النطاقات إلى عناوين IP.
  • TCP: اتصال موثوق يرتب البيانات ويتابع وصولها.
  • UDP: يرسل البيانات دون ضمان تسليمها.
  • HTTP: غالبًا المنفذ 80.
  • HTTPS: غالبًا المنفذ 443.
  • SSH: غالبًا المنفذ 22.

حماية الشبكة

  • فعّل WPA2-AES أو WPA3 للواي فاي.
  • غيّر كلمة مرور إدارة الراوتر الافتراضية.
  • حدّث نظام الراوتر.
  • افحص أجهزتك وشبكتك فقط، أو أي شبكة لديك إذن واضح لاختبارها.

أمن تطبيقات الويب

Web Application Security

ثغرات شائعة

  • SQL Injection: تلاعب باستعلامات قاعدة البيانات؛ الوقاية باستخدام الاستعلامات المعلّمة Prepared Statements.
  • XSS: تنفيذ محتوى غير موثوق في المتصفح؛ الوقاية بترميز المخرجات والتحقق من المدخلات.
  • CSRF: خداع متصفح المستخدم لإرسال طلب غير مرغوب؛ من وسائل الوقاية CSRF Tokens وSameSite Cookies.
  • HTTPS: يحمي البيانات أثناء انتقالها بين المتصفح والخادم.

نصائح للمطورين

  • لا تخزن كلمات المرور كنص صريح.
  • تحقق من صلاحيات المستخدم على الخادم.
  • لا تضع مفاتيح API السرية في كود الواجهة.
  • استخدم رسائل أخطاء لا تكشف تفاصيل حساسة.

اختبار سريع

التشفير

Cryptography

أنواع أساسية

  • AES: تشفير متماثل يستخدم المفتاح نفسه للتشفير وفك التشفير.
  • RSA: خوارزمية مفتاح عام ومفتاح خاص.
  • SHA-256: دالة Hash لإنتاج بصمة للبيانات وليست تشفيرًا قابلًا للفك.
  • Password Hashing: يفضل استخدام Argon2id أو bcrypt أو scrypt لتخزين كلمات المرور.

ممارسات آمنة

  • لا تخترع خوارزمية تشفير بنفسك.
  • استخدم مكتبات موثوقة ومحدثة.
  • احمِ المفاتيح السرية ولا تضعها داخل المستودعات العامة.

اختبار سريع

الاختراق الأخلاقي

Ethical Hacking

المبدأ الأساسي

اختبار أمان الأنظمة بموافقة صاحبها وضمن نطاق واضح ومحدد. وجود إذن لاختبار جهاز لا يعني وجود إذن لاختبار أجهزة أخرى على الشبكة.

مراحل العمل

  • تحديد النطاق والإذن.
  • جمع المعلومات المسموح بها.
  • فحص الإعدادات والخدمات.
  • التحقق الآمن من النتائج.
  • توثيق الثغرات واقتراح الإصلاحات.

أدوات تتعلمها

  • Nmap: استكشاف الشبكات التي تملك إذنًا بفحصها.
  • Wireshark: تحليل حركة الشبكة.
  • Burp Suite: اختبار تطبيقات الويب المصرح بها.
  • Linux: تعلم سطر الأوامر وإدارة الملفات.

معمل الأوامر

Browser Terminal Lab

قبل البداية

التيرمينال ده بيستخدم بيئة WebContainer داخل المتصفح، وده مش تيرمينال أندرويد أو Kali Linux كامل. يحتاج متصفحًا متوافقًا واتصالًا مناسبًا، ويعمل أفضل عبر HTTPS أو localhost.

جرّب الأوامر التعليمية: help، pwd، ls، echo Hello، mkdir test.

WAITING

لو البيئة الحقيقية غير مدعومة على جهازك، هتظهر رسالة واضحة بدل الشاشة السوداء. الأوامر السريعة بتوضح أمثلة تعليمية، وليست وصولًا إلى نظام هاتفك.
